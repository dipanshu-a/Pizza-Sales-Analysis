# 🍕 Pizza Sales Analysis

An end-to-end **Data Analytics project** focused on analyzing pizza sales data using **Python, NumPy, Pandas, Matplotlib, and Power BI**.

The project focuses on understanding sales performance, order trends, customer ordering patterns, pizza categories, pizza sizes, and time-based sales behavior. Python was used for data preparation and exploratory analysis, while Power BI was used to build an interactive business dashboard.

---

## 📌 Project Overview

The objective of this project is to transform raw pizza sales data into meaningful business insights through data cleaning, exploratory data analysis, visualization, and interactive dashboarding.

The project follows an end-to-end analytics workflow:

**Raw Data → Data Cleaning → Data Analysis → Visualization → Business Insights → Power BI Dashboard**

---

## 🎯 Business Objectives

The main objectives of this project are:

* Analyze overall pizza sales performance
* Understand daily and time-based order trends
* Identify the most ordered pizzas
* Identify pizzas generating the highest sales
* Analyze sales by pizza category
* Analyze customer preference by pizza size
* Identify high-performing and low-performing areas
* Track important business KPIs
* Build an interactive dashboard for business analysis
